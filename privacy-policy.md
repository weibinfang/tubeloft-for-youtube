# Privacy Policy — TubeLoft for YouTube

**Effective date:** August 24, 2026

TubeLoft for YouTube ("the Extension") is a browser extension that enhances
the YouTube watch page with a tabbed sidebar, playback speed control, a
stylized progress bar, visual ad marking and a watch-history popup.

## Data We Collect

**None.** The Extension does not collect, store, transmit or share any
personal information or usage data. Specifically:

- No personal identification information (name, email address, etc.)
- No browsing history or network logs
- No analytics, tracking pixels or telemetry of any kind
- No data is ever sent to any server operated by us or any third party

## Local Storage Only

All Extension settings (feature toggles, playback speed preference) are
stored exclusively in your browser's local storage and never leave your
device. Deleting the Extension removes this data.

## YouTube Session Access

The watch-history popup requests pages on youtube.com using your browser's
existing YouTube session in order to display **your own** watch history to
you. This data is rendered locally, is never stored by the Extension beyond
the current popup session, and is never transmitted anywhere.

## Third Parties

The Extension interacts only with youtube.com. It contains no third-party
SDKs, advertising or analytics services.

## Changes

If this policy ever changes, the updated version will be published at this
URL and reflected in the Extension's store listing.

## Contact

If you have questions about this policy, please contact the developer via
the Chrome Web Store listing page for TubeLoft for YouTube.
